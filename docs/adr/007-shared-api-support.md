# ADR 007. Общий контракт ошибок

Статус: принято. Дата фиксации: 2026-11-02.

## Контекст

Три HTTP-приложения должны возвращать одинаковые семь полей ApiError. Копии DTO,
/error и протокольных обработчиков создавали риск расхождения ответов.

## Решение

api-support — обычная Maven-библиотека с ApiError, /error, базовыми обработчиками
MVC и помощниками Spring Security. Сервисы подключают advice короткими классами;
доменные исключения и их коды остаются локальными. Gateway расширяет обработку
обёрнутых транспортных ошибок до 503. Приоритеты обработчиков сохранены.
Библиотека сама не включает security у потребителя и не содержит JPA-сущности.

## Последствия

Изменение общей ошибки проверяется контрактными тестами каждого HTTP-приложения.
Библиотеку нужно собирать в Maven reactor вместе с потребителями. Это общая
кодовая зависимость, но не общий runtime-сервис или БД. Версии и контракт требуют
согласованного обновления. [Ошибки и структура библиотеки](../api-errors-security.md).
