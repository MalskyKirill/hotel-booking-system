# Стиль Java

Все Java-исходники форматируются google-java-format 1.24.0 через Spotless Maven
2.44.3. Версии и правила закреплены в корневом pom.xml и наследуются модулями.
Форматтер использует отступ в два пробела, единые переносы и порядок импортов;
неиспользуемые импорты удаляются.

```sh
# Применить форматирование, включая необязательный модуль системных тестов
mvn -B -ntp -Psystem-tests spotless:apply
# Проверить без изменения файлов
mvn -B -ntp -Psystem-tests spotless:check
```

Проверка привязана к фазе validate, поэтому нарушения останавливают package и
verify. GitHub Actions уже выполняет -Psystem-tests clean verify и проверяет
все модули. Обычная сборка без профиля не включает system-tests.

Перед коммитом запускайте apply с профилем system-tests. При настройке IDE
выбирайте ту же версию google-java-format либо используйте Maven. Обновление
форматтера выполняется отдельным изменением от изменений поведения приложения.
